# quorum-guard
CENG 3550 course project exploring multi-party approval and tamper-evident audit logs for critical administrative operations, with evaluation against a centralized baseline.
Ders: CENG 3550 — Decentralized Systems and Applications
Amaç: Kritik yönetici işlemleri için çok taraflı onay ve doğrulanabilir kayıt tasarlamak.
İlk örnek: Laboratuvar ortamında örnek yedek silme işlemi.
Değerlendirme: Merkezi alternatifle güvenlik, gecikme, kullanılabilirlik ve kayıtların eksiksizliğini karşılaştırmak.
Mevcut durum: Öneri ve tasarım aşaması; teknoloji seçimi henüz kesinleşmedi.
